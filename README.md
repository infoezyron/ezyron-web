# ezyron-web

Web pública de **Ezyron**, publicada con GitHub Pages.

- El código de trabajo vive en el repo privado `infoezyron/ezyron` (carpeta `web/ezyron-punto`).
- Este repo solo contiene lo que se publica: `index.html` en la raíz.
- Cualquier cambio entra por pull request. Al fusionar en `main`, GitHub Pages actualiza la web en uno o dos minutos.
