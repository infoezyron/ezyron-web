# ezyron-web

Web pública de **Ezyron**, publicada en https://ezyron.com (Hostinger, despliegue desde Git).

- El código de trabajo vive en el repo privado `infoezyron/ezyron` (carpeta `web/ezyron-punto`).
- Este repo solo contiene lo que se publica: `index.html` y sus iconos en la raíz.
- Hostinger despliega la rama `main` en `public_html`. Cualquier cambio entra por pull request; al fusionar en `main`, la web se actualiza sola (webhook de despliegue automático).
